# ServiceSpeak AI

**ServiceSpeak AI** is a bilingual, mobile-first Business English learning prototype designed for students preparing for passenger-service careers, including flight-attendant and high-speed railway service roles.

The project explores how AI-assisted language learning can support **workplace communication, personalised review, listening practice, feedback, and critical evaluation of AI-generated language** while keeping teacher judgement central to the learning process.

## Why this project

In passenger-service English, grammatical correctness alone is not enough. Learners also need to respond appropriately to real situations, understand spoken language under pressure, maintain a professional service tone, and make pragmatic choices according to context.

ServiceSpeak AI was designed around that gap between **correct language** and **successful communication**.

## 7-Day Pilot

The current student pilot contains seven workplace scenarios:

1. Handling a Flight Delay
2. Baggage Problem
3. Seat Change Request
4. Meal & Special Request
5. Passenger Complaint
6. Tight Connection
7. Integrated Service Challenge

Each day combines:

- Workplace vocabulary retrieval
- Listening and dictation
- Scenario-based response practice
- AI-output judgement: **Accept / Revise / Reject**
- Personalised review
- Points, streaks, progress tracking, and achievement badges

## Critical AI Literacy

A key feature of the project is that students do not simply receive an AI answer and accept it.

They are asked to evaluate whether a proposed response is appropriate for the situation, decide whether to **accept, revise, or reject** it, and reflect on features such as:

- task completion
- grammatical accuracy
- pragmatic appropriateness
- service tone
- empathy
- professional communication

This design treats AI literacy as a matter of **critical judgement**, not merely tool use.

## Current Prototype

The current 7-day pilot is a self-contained web application that runs in a modern browser and supports:

- English / Traditional Chinese interface
- randomised answer positions
- immediate correct / incorrect sound feedback
- daily unlocking and completion tracking
- student nickname and pilot ID
- local progress storage
- personalised review summaries
- exportable learning records

### AI status

The current public pilot uses **transparent rule-based feedback and simulated AI-response evaluation** so that the learning design can be tested safely before live model integration.

A later phase will add model-based conversational role-play and dynamic feedback while retaining teacher-defined rubrics and human oversight.

## Intended Users

The prototype is designed primarily for tertiary vocational students preparing for passenger-facing service roles.

## Development Direction

Planned next steps include:

- live AI role-play
- teacher dashboard and class-level analytics
- adaptive review based on learner error patterns
- expanded listening and speaking tasks
- pilot evaluation with real learners
- iterative redesign based on student performance and feedback

## Responsible Use

The project is designed around the principle that AI should support, rather than replace, teacher judgement. AI-generated language should be reviewed for quality, context, appropriateness, and learner impact before being used in teaching.
